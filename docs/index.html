What it scans

CodeFence runs 30 rules across Python and JavaScript, mapped to 29 CWE identifiers. It targets the risky patterns that AI coding assistants commonly produce:

  • Hardcoded API keys and secrets
  • SQL injection via string concatenation
  • Command injection with shell=True
  • eval() / exec() on untrusted input
  • Insecure random for security tokens
  • Broad except: pass
  • And 24 more rules

Frequently asked

Does CodeFence phone home?

Free tier: zero network calls during scans. Pro activation: exactly one call, once per machine, to validate the license. After that, CodeFence runs fully offline forever.

Do I need an account?

No. No account, no email, no signup.

Is there a refund policy?

Getly offers a 30-day money-back window on every product page. Buyers can request a refund directly through Getly.

What if I lose my license key?

The license key is the sole proof of purchase. Back it up as you would an SSH key or password. CodeFence has no recovery channel.

Is this a security audit?

No. CodeFence is a pattern-based sanity check for selected dangerous patterns. It is not a replacement for Semgrep, CodeQL, or professional review.

How many devices can I use one license on?

One individual on up to 3 devices they own or control.

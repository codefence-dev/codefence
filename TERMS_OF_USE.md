## 1. What the Software is

CodeFence is a **pattern-based sanity checker** for source
code. It scans Python and JavaScript files for a curated set of
dangerous patterns (hardcoded secrets, injection sinks, weak
cryptography, insecure configuration) and reports them.

It is NOT:

- a security audit,
- a vulnerability scanner in the enterprise sense,
- a replacement for professional security review,
- a guarantee that scanned code is secure, correct, or complete.

A clean scan does **not** mean the code is secure.
